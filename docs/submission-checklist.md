# Final submission checklist

Target readiness: December 3, 2026. Canvas deadline: December 10, 2026. The team
must designate its uploader. A repository link supplements the required files;
it does not replace uploading them to Canvas.

- [ ] Analytical report is approximately 10–12 double-spaced pages, with readable font.
- [ ] References and appendices are excluded from the main report page count.
- [ ] Additional exhibits/appendices do not exceed 10 pages.
- [ ] Report explains the decision, main questions, findings, mathematical model,
      data/assumptions, verification, benchmark/scenarios, and recommendations/limits.
- [ ] Both required alternative scenarios are presented and interpreted.
- [ ] Comparisons use equivalent completed workloads and accurate solver statuses.
- [ ] Python source and all required data are included.
- [ ] README dependencies, solver requirements, and analysis commands reproduce key results.
- [ ] A clean unpacked package has been tested on an agreed team environment.
- [ ] Brief AI-use statement identifies major tools, contributions, and verification.
- [ ] Track A recording format is confirmed and recording is included.
- [ ] All four members have supplied their work and reviewed the full package.
- [ ] Final filenames, versions, and upload contents are checked by the designated uploader.
- [ ] Required files and recording are submitted to Canvas; receipt is verified.

The source archive workflow is a repository snapshot utility. It does not create
or certify the final course submission, and it intentionally excludes generated
outputs and large recordings. Anete assembles the final package from completed,
reviewed deliverables.

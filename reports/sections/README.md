# Report sections and ownership

Each member supplies polished writing for their own section. Anete combines
completed sections; she is not responsible for writing everyone else's work.

| Section | Lead |
| --- | --- |
| Decision problem, data, assumptions | Dora |
| Mathematical model and independent verification | Josh |
| Numerical results, benchmark, scenarios | Izzy |
| Recommendations, limitations, integrated report | Anete |

Include the main questions and a summary of findings in the integrated report.
The format of working section files can be agreed by the team. Avoid concurrent
edits to the same binary document; use a named integration owner and focused PRs.
All four members review the completed report and submission.
